API Reference

Four powerful API categories

All built on RESTful architecture with predictable resource-oriented URLs, JSON responses, and standard HTTP status codes.

Calculation Results

Access LCA calculation results, design summaries, and project-level carbon data from any OCL project.

LCA Modeling API

Projects and designs are where BOMs, manufacturing inputs, and LCA models come together—calculated in One Click LCA and delivered through reports and linked outputs. Use these endpoints to integrate that workflow programmatically, subject to your licence.

Materials & Carbon Data

Search 0.5M+ EPDs, access carbon impact data, download EPD files, and retrieve master data.

EPD Generation

Generate product EPDs via API—send product and BOM data through the orchestration workflow and receive EPD outputs.
